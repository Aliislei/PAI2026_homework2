## 動画の設定（YouTube）

- **長さ**: 1分〜3分以内
- **倍速**: 2倍速まで可。倍速にした場合は動画内または概要欄に明記する
- **タイトル**: `PAI最終課題_omnicampusアカウント名` または `PAI最終課題_アカウントID`
  - 個人名をアカウント名にしている場合は、アカウントIDを使う
- **公開設定**: 「限定公開」が最低条件。「公開」を推奨（優秀生選出の際に加点対象）
- **子ども向け動画**: いいえ
- **年齢制限**: いいえ
- **インスタントプレミアム公開**: チェックしない
- **プレミア公開として設定する**: チェックしない
- **予約公開**: 使う場合は、提出締切までの日時を設定する
- **採点完了まで**: 動画を削除・非公開にしない

## omnicampus での提出手順

1. omnicampus の「レポート」を開く
2. 「レポートのタイトル」に `[omnicampusアカウント名].pdf` を入力する（違っていても採点に影響なし）
3. **Q1**: YouTube の動画リンクを入力する（シークレットウィンドウで開けることを確認）
4. **Q2**: YouTube の公開設定を入力する
5. **Q3**: GitHub リポジトリのURLを入力する（シークレットウィンドウで開けることを確認）
6. **Q4**: 提出物に個人情報が含まれていないことを確認し、「確認しました」と入力する
7. 「提出ファイル」からレポートPDFを選択し、プレビューを確認する
8. 「提出する」をクリックする（アップロード中はリロードやページ移動をしない）
9. 「レポートが提出されました🎉」の表示と提出日時を確認する

優秀生選出を希望する場合は、提出後に表示される「最終課題_優秀生選出用」から、同じ手順でもう一度提出する。修了判定は「最終課題」の提出物で行われる。

## 個人情報と公開範囲の注意

- PDF、コード、動画には、**氏名・所属・メールアドレスなどの個人情報を記載・映り込みさせない**
- omnicampus のアカウント名は記載してよい
- 提出物は他の受講者に公開される可能性がある。受講者外に出せない秘密情報を含めない
- 優秀作品は、本人の許可を得た上で松尾研公式 YouTube チャンネルのプレイリスト等で公開予定

## 評価基準

**合格ライン**: ロボットがタスクを実行している動画と提出物を提出すること。

**加点要素**:

- **創造性**: 独自性のあるアイデアやアプローチ
- **技術力**: 高度な技術や複雑な制御の実装
- **実用性**: 現実世界での応用可能性
- **表現力**: 動画の構成や説明のわかりやすさ

**失格につながる行為**: 他人の作品の剽窃、最終課題サンプルの丸写し、明らかに関係のないファイルの提出など。修了判定の対象外となる可能性がある。

サンプルはベースラインとして使うことが想定されている。発展させた上で、工夫点をレポートに明記する。

完成に至らなかった場合でも、最後まで取り組んだ上で反省点や考察をレポートに記載していれば、優秀生に選ばれる可能性がある。
