# 取り組みテーマ

**対象物アプローチにおけるリストカメラ画像による深度推定の重要性および、それを最適に保つための推論間隔調整**

## 背景

pi05 のように深度画像を持たない VLA モデルでは、対象物とアームの距離推定は、主にリストカメラ画像に写る物体のスケールに依存する形で学習されていると推測する。

物体スケールに基づく深度推定を正確に行うには、対象物との適切な距離感が重要である。距離によっては、深度推定の精度が落ちると考えられる。

一方、タスク実行時の対象物アプローチでは、推論間隔の都合上、どの距離で推論が入るかを選べない。

## 仮説

- 深度画像を持たない VLA モデルの距離推定は、リストカメラ画像の物体スケールに主に依存している
- 対象物との距離には、チャンクの下降量が実際の距離に最も合う、適切な範囲が存在するはずである

物体スケールへの依存は、現時点では未検証の推測である。

当初は「近いほど距離を推定できなくなる」と考えていたが、1000 ロールアウトの測定で単調な悪化は見られなかったため、上記のように弱めた。

## 検証すること

対象物の直近で推論したときに、出力されたアクションチャンクが対象物との距離を正しく捉えた内容になっているかを確認し、仮説を立証する。

### 検証方法

1. Libero の pick&place 系タスクのみを対象に、短めの推論間隔、固定シードで多エピソード実行する
2. 推論が入ったタイミングのシミュレータ状態と、方策が出したアクションチャンクをすべて記録する
3. 推論時点の対象物との高さの差と、アクションチャンクが出した下降距離を比較分析する
4. 異常な下降距離を出しているロールアウトを抽出する

異常な下降距離を出すロールアウトは存在すると見込んでいるが、未確認である。

### 分析の設計メモ

実装は `notebooks/collect_and_analyze.ipynb` にある。Colab で実行して妥当性を確認する。

- **推論ごとの指標**: `誤差 = チャンクの下降距離 - 必要な下降距離`。正なら突っ込みすぎ、負なら届かない
- **必要な下降距離**: `手先の高さ - 対象物の高さ - 把持オフセット`。把持オフセットは、対象物に降りたロールアウトのアプローチ完了時の `手先の高さ - 対象物の高さ` の、タスクごとの中央値とする
- **換算係数**: 固定窓（10 ステップ）の実際の高さ変化と、z アクションの合計から実測する
- **アプローチ完了**: 閉指令の開始後に z 指令が下降でなくなる点。閉指令は 1 ステップで切り替わるが、手先はその後も数ステップ下降を続けるため、閉指令の開始点は使わない。実行軌跡とチャンクの両方に同じ定義を適用する
- **チャンクの下降距離**: チャンクは全量を記録し、先頭からアプローチ完了までの累積で測る。実行ステップ数（推論間隔）には依存しない
- **対象区間**: 実行軌跡のアプローチ完了より前の推論を使う。閉指令の開始後の推論も含むが、配置先への下降は混ざらない
- **対象ロールアウト**: タスクの成否は問わない。アプローチ完了時に手先が対象物の近くにいないものだけ除く
- **距離ごとの集計**: 推論時点の高さの差ごとに、誤差の平均と裾（p10、p90）を集計する。仮説が正しければ、誤差の小さい距離の範囲が見つかるはずである
- **サンプリングのばらつき**: 固定シードで該当ステップまで再現し、そこからシミュレータを進めずに同じ入力で推論を繰り返す。これにより、たまたまの外れ値と距離に起因する誤差を分ける
- **再現の確認**: 再現したステップのシミュレータ状態を、記録時の状態と照合してから推論を繰り返す。繰り返し推論では、サンプリングの乱数だけを毎回変える

## 検証結果

1000 ロールアウト、9,321 推論の測定結果である。値は `計画下降距離 - 実際の下降距離` で、正が突っ込みすぎである。

- 14〜20cm: 平均がほぼ 0 で、両側の裾も約 ±3cm に収まる
- 8〜12cm: p90 が 7.4〜8.7cm と最も悪い。`libero_spatial` の 10〜12cm では 10.7cm に達する
- 25cm 超: 届かない側に寄る（平均 -1.7cm）

## 対策の結果

予定軌道の最下点までの距離が 16cm を下回ったら、アプローチ完了の 10 ステップ後まで再推論を止める。対象物の位置は使わない。

200 本の対応比較では、下降指令中に高さが動かないステップ数は 3.81 から 3.43 になったが、有意な改善ではない（p=0.54）。個別には大きく改善した例と、変わらなかった例がある。

## 提案（条件付き）

アプローチの突っ込みすぎ、または届かないケースが確認できた場合、次の推論間隔調整機能を提案する。

- 正常な距離感を把握できるうちにアクションチャンクを生成する
- アプローチから把持完了まで、再推論を挟まない
